# Визуальный и структурный аудит (15-часовой план)

Дата: 2026-11-18  
Проект: `E:\camp-race` (Next.js 16 + React + TypeScript + Tailwind)  
Фокус: **визуал и структура** (без итераций/изменений логики данных сверки).

## Что реализовано

### Блок 1 — Система и структура (завершён)
- **Дизайн-токены и база (`src/app/globals.css`)**: расширенные CSS-переменные (бренд `#4c008e`, акценты `#f2b705`, поверхности, тени, радиусы), глобальный фон с градиентами, `selection`, `focus-visible`, сглаженные переходы.
- **Motion-система**: `fadeUp/fadeIn/rise/pop/pulseGlow/shimmer/gradientMove/float`, утилиты `.glass`, `.card-surface`, `.grain`, `.section-wrap`; поддержка `prefers-reduced-motion`.
- **Навигация/структура**: `SiteHeader` переведён в client-компонент — scroll-aware фон, прогресс-бар скролла, якорные ссылки (Цель/Рейтинг), CTA в админку.
- **Layout/мета (`src/app/layout.tsx`)**: обновлённые title/description/Open Graph под «Гонка регионов».

### Блок 2 — Hero и первое впечатление (завершён)
- **Редизайн hero (`src/app/page.tsx`)**: новая композиция (слоистый фон hero-bg + градиенты + grain + glow), выразительная типографика, индикатор «гонка идёт», бейдж лидера, CTA, таймер, расширенные KPI-карточки с count-up.
- **Визуал камп-фото**: маска (radial mask), глубина, рамка/свечение, floating-карточка с общим числом активистов.
- **Адаптив**: отдельные пропорции/плотность контента для мобильных и десктопа, компактные статусы.

### Блок 3 — Визуализация гонки (завершён)
- **`GoalProgress`**: кольцевой сводный индикатор (SVG), карточки регионов с прогрессом/статусом «ГОТОВО», подписи «сверх порога / осталось», shimmer-акцент.
- **`SnapshotTimeline`**: визуальная шкала 5 срезов, нумерация шагов, дельты, подсветка текущего среза, улучшенные бары и анимации появления.
- **`Leaderboard`**: подиум топ-3 (при сортировке по активистам), ранговая иерархия, бейджи «Лидер/Прорыв/Порог достигнут», усиленные прогресс-бары, тренд-спарклайны (area+line), улучшенный поиск/сортировки, hover/motion.
- **`RegionDetailsModal`**: bottom-sheet friendly, hero-заголовок региона, метрики, воронка с конверсией шагов, разбор отклонений с барами, таблица городов с вкладом (% и бар), анимация появления.

### Блок 4 — Делайт, шаринг, motion (завершён)
- Единые анимации появления (`rise`, stagger), hover-подъём карточек, пульс «live», акценты лидера/прорыва, shimmer на прогрессах.
- **`ShareCardGenerator`**: переработанная фирменная PNG-карточка (градиенты, топ-5, % порога, прирост, сводка в цели), улучшенный текст шаринга и обратная связь «скопировано».
- Информационные блоки прозрачности/CTA на главной, улучшенный футер.

### Блок 5 — Админка, адаптив, a11y, финал (завершён)
- **Админка (`src/app/admin/page.tsx`)**: брендированный sticky header, шаги процесса (загрузка/сверка → предпросмотр/публикация), усиленные секции/карточки, визуальная иерархия, улучшенные кнопки и контейнеры; сохранена вся функциональность.
- **Адаптив/полировка**: консистентные радиусы/тени/бордеры, карточные состояния, улучшенные таблицы/обёртки, touch-friendly элементы.
- **Доступность**: `focus-visible`, семантичные aria для модалки, контрастные акценты, `prefers-reduced-motion`.
- **Проверка**: `npm run build` — успешно (TypeScript и статическая генерация пройдены).
